#### Tallennettu funktio (Stored Function): LaskeHinta

"Luo funktio, joka ottaa parametreina auton ID:n, varauksen alkup‰iv‰n ja loppup‰iv‰n.

Funktio laskee ja palauttaa varauksen kokonaishinnan (p‰ivien m‰‰r‰ $\times$ auton p‰iv‰hinta)."

https://www.tutorialspoint.com/mysql/mysql-stored-functions.htm

Esim:
```SQL
DELIMITER $$
CREATE OR REPLACE FUNCTION LaskeHinta(IN p_auto_id INT, IN p_varaus_alkaa DATETIME, IN p_varaus_paattyy DATETIME)
RETURNS DECIMAL(8,2)
DETERMINISTIC
BEGIN
	DECLARE kokonaishinta DECIMAL(8,2);
	DECLARE paivien_maara int;
	DECLARE paivahinta DECIMAL(8,2);

	SET paivien_maara = DATEDIFF(p_varaus_paattyy, p_varaus_alkaa);
	SELECT auto.paivahinta INTO paivahinta
	FROM autot auto
	WHERE auto.auto_id = p_auto_id;

	SET kokonaishinta = paivahinta * paivien_maara;

	RETURN kokonaishinta;
END$$
DELIMITER ;
```

Funktion kutsuesimerkki:

```SQL

SELECT LaskeHinta(1, '2026-05-1', '2026-05-6') AS kokonaishinta;

-- palauttaa arvon: 225, joka on 45 * 5.
```

Mutta v‰h‰n t‰t‰ asiaa tutkiessani tulin siihen p‰‰tˆkseen, ett‰ vuokraustavat ja maksut vaihtelevat aika paljon eri yrityksien v‰lill‰, ett‰ annan nyt t‰m‰n olla vain t‰m‰n autoliikkeen tapa maksuttaa.


#### Tallennettu proseduuri (Stored Procedure): TeeVaraus

"Proseduuri ottaa parametreina asiakkaan ID:n, auton ID:n, alkup‰iv‰n ja loppup‰iv‰n.

Transaktio: Proseduurin sis‰ll‰ on k‰ytett‰v‰ transaktiota (START TRANSACTION, COMMIT, ROLLBACK).

Logiikka: Tarkista ensin, onko auto vapaana kyseisen‰ ajankohtana. Jos on, lis‰‰ rivi Varaukset-tauluun ja p‰ivit‰ auton tila Autot-taulussa. Jos auto on jo varattu, peruuta transaktio ja nosta virheilmoitus (SIGNAL SQLSTATE)."

```SQL=
DELIMITER $$
CREATE OR REPLACE PROCEDURE TeeVaraus(IN p_asiakas_id INT, IN p_auto_id INT, IN p_varaus_alkaa DATETIME, IN p_varaus_paattyy DATETIME)
BEGIN
DECLARE varauksien_maara INT;

START TRANSACTION;

SELECT COUNT(*) INTO varauksien_maara FROM Varaukset v
WHERE v.auto_id = p_auto_id
AND v.varaus_alkaa < p_varaus_paattyy
AND v.varaus_paattyy > p_varaus_alkaa
AND v.auto.tila = 'vapaa';

IF varauksien_maara = 0 THEN
    
    INSERT INTO Varaukset(
    varaus_alkaa,
    varaus_paattyy,
    kokonaishinta,
    asiakas_id,
    auto_id) 
    VALUES(
    p_varaus_alkaa,
    p_varaus_paattyy,
    LaskeHinta(p_auto_id, p_varaus_alkaa, p_varaus_paattyy),
    p_asiakas_id,
    p_auto_id);

    UPDATE Autot
    SET Tila = 'varattu'
    WHERE auto_id = p_auto_id;
    
    COMMIT;

ELSE
	ROLLBACK;
	SIGNAL SQLSTATE '45000' SET MESSAGE_TEXT = 'Auto on varattuna valittuna ajankohtana';
END IF;

END$$
DELIMITER ;
```

T‰ytyy sanoa, ett‰ transactioneita pit‰isi k‰ytt‰‰ useammin ihan kyselyit‰ tehdess‰. Olisin s‰‰stynyt monelta p‰‰nvaivalta. Tosin

##### 1. Ongelmatilanne: Auton tilan p‰ivitys

### Vaihe 3: Triggerit ja automaatio

Huom. K‰ytin nime‰misess‰ seuraavia k‰yt‰ntˆj‰:

#### Audit-loki (AFTER UPDATE)

"Luo triggeri Autot-tauluun. Aina kun auton tila muuttuu arvoon 'huollossa', triggerin tulee automaattisesti lis‰t‰ tietue Loki-tauluun (esim. "Auto [rekisterinumero] siirretty huoltoon")."

```SQL
	IF NEW.tila = 'huollossa' THEN
		INSERT INTO Loki(toimenpide, aikaleima,	kenen_tekema)

END$$
DELIMITER ;
```



#### Turvatarkistus (BEFORE INSERT):

"Luo triggeri Varaukset-tauluun, joka est‰‰ p‰‰llekk‰iset varaukset tietokantatasolla. Jos uusi varaus osuu aikav‰lille, jolloin auto on jo varattu, triggerin tulee pys‰ytt‰‰ operaatio ja palauttaa virhe."

```SQL

END$$
DELIMITER ;
```

```SQL
DELIMITER $$
CREATE EVENT PaivitaAutojenTilat
    ON SCHEDULE
      EVERY 1 DAY
	STARTS CURRENT_DATE + INTERVAL 23 HOUR + INTERVAL 59 MINUTE

      BEGIN
```

```SQL
-- Luo funktio, joka ottaa parametreina auton ID:n, varauksen alkup‰iv‰n ja loppup‰iv‰n.
-- Funktio laskee ja palauttaa varauksen kokonaishinnan (p‰ivien m‰‰r‰ $\times$ auton p‰iv‰hinta).
DELIMITER $$
CREATE OR REPLACE FUNCTION LaskeHinta(IN p_auto_id INT, IN p_varaus_alkaa DATETIME, IN p_varaus_paattyy DATETIME)
RETURNS DECIMAL(8,2)
DETERMINISTIC
BEGIN
	DECLARE kokonaishinta DECIMAL(8,2);
	DECLARE paivien_maara int;
	DECLARE paivahinta DECIMAL(8,2);

	SET paivien_maara = DATEDIFF(p_varaus_paattyy, p_varaus_alkaa);
	SELECT auto.paivahinta INTO paivahinta
	FROM autot auto
	WHERE auto.auto_id = p_auto_id;

	SET kokonaishinta = paivahinta * paivien_maara;

	RETURN kokonaishinta;
END$$
DELIMITER ;

-- Tallennettu proseduuri (Stored Procedure): TeeVaraus
-- Proseduuri ottaa parametreina asiakkaan ID:n, auton ID:n, alkup‰iv‰n ja loppup‰iv‰n.
-- Transaktio: Proseduurin sis‰ll‰ on k‰ytett‰v‰ transaktiota (START TRANSACTION, COMMIT, ROLLBACK).
-- Logiikka: Tarkista ensin, onko auto vapaana kyseisen‰ ajankohtana.
-- Jos on, lis‰‰ rivi Varaukset-tauluun ja p‰ivit‰ auton tila Autot-taulussa.
-- Jos auto on jo varattu, peruuta transaktio ja nosta virheilmoitus (SIGNAL SQLSTATE).
DELIMITER $$
CREATE OR REPLACE PROCEDURE TeeVaraus(IN p_asiakas_id INT, IN p_auto_id INT, IN p_varaus_alkaa DATETIME, IN p_varaus_paattyy DATETIME)
BEGIN
	DECLARE varauksien_maara INT;

	START TRANSACTION;


	SELECT COUNT(*) INTO varauksien_maara FROM Varaukset v
	WHERE v.auto_id = p_auto_id
	AND v.varaus_alkaa < p_varaus_paattyy
	AND v.varaus_paattyy > p_varaus_alkaa;

	IF varauksien_maara = 0 THEN

		INSERT INTO Varaukset(
		varaus_alkaa,
		varaus_paattyy,
		kokonaishinta,
		asiakas_id,
		auto_id

		) VALUES(
		p_varaus_alkaa,
		p_varaus_paattyy,
		LaskeHinta(p_auto_id, p_varaus_alkaa, p_varaus_paattyy),
		p_asiakas_id,
		p_auto_id
		);

		UPDATE Autot
		SET Tila = 'vuokralla'
		WHERE auto_id = p_auto_id;
		COMMIT;

	ELSE
		ROLLBACK;
		SIGNAL SQLSTATE '45000' SET MESSAGE_TEXT = 'Auto on varattuna valittuna ajankohtana';

	END IF;

END$$
DELIMITER ;

-- Audit-loki (AFTER UPDATE):
```
